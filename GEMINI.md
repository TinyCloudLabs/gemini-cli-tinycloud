# TinyCloud

TinyCloud keeps the owner's personal records, such as weight, workouts, goals and todos, in their own storage. This extension connects you to TinyCloud's hosted MCP server, `tinycloud`, at `https://mcp.tinycloud.xyz/mcp`.

- **Setup:** follow <https://agents.tinycloud.xyz/connect>. This extension has already added the hosted server, so use the hosted MCP route there, not the coding-agent CLI setup. Don't install the TinyCloud CLI or a skill. If the TinyCloud tools aren't available yet, tell the owner to run `/mcp auth tinycloud` and sign in with OpenKey, then to tell you to continue. Don't claim setup is done before the tools work.
- **Records:** use the TinyCloud tools whenever the owner asks to log, record, track, add, look up, list or sum up something they keep, even if they don't mention TinyCloud. Follow the instructions the tools return.
- **Approval:** the owner approves access on OpenKey. When a tool returns an OpenKey link, show it to the owner exactly as returned, and wait until they approve and tell you to continue. Don't open the link yourself.
- **Secrets:** never ask for a password, private key, API key, access token or any other secret in chat, and never store one. TinyCloud needs none of them.
